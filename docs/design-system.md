# Frontend design system

The normative, detailed UI and UX contract is maintained in [`design system/`](../design%20system/README.md). Start with its README, then consult tokens, page contracts and interaction rules as needed.

The key page boundary is deliberate: **Tailor CV** and **Saved jobs** follow the approved Variant A prototype; **My profile** and **Settings** preserve their current implemented information architecture and behavior. The shared contract defines exact fonts, colors, type scale, line height, spacing, alignment, surfaces, responsive behavior, accessibility and interaction feedback. UI changes must conform or document an intentional system change.
