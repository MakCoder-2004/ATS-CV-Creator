# Direct public posting intake, integration wave 1

This is a source-branch validation note, not release or installed-app evidence. The renderer still uses Lever wording until its separately owned UI update lands.

- `src/main/workbench.ts` routes legacy Lever links to the existing adapter and normalized public LinkedIn, Indeed and generic URLs to one bounded direct read. A LinkedIn search URL with `currentJobId` requests the exact canonical detail URL, not the search or login page. Full exact-role source text with title and employer becomes an editable temporary preview. Incomplete, blocked, ambiguous or employerless results have a research notice and cannot be saved. No search provider or model dispatch runs on fetch.
- Accepted full captures use `linkedin-public-html-v1` or `public-jsonld-v1`, canonical HTTPS URLs and source-specific identity. Existing Lever methods, stored records and released v2 backup parsing remain unchanged. New direct snapshots parse under current `jobRecordSchema`; current backup validation uses that schema. Full direct text is saved by explicit review, so source-content retention and redistribution rights remain a human release gate.
- The existing `prepareOutboundConsent` → `acceptOutboundConsent` → `startAnalysis` binding remains the only path from the newly saved job to model analysis. This wave does not enable indexed fallback, provisional consent/analysis, company background, query sharing, a Tavily account/key or an automatic model request.
- Focused proof is `tests/universal-direct-workbench.test.ts`. It exercises synthetic selected-URL transport, preview edit/review/save, backup serialization, duplicate identity, explicit consent and a current analysis run; it includes a real inert extraction-worker fixture. `tests/jobs.test.ts` and `tests/safe-posting-fetch.test.ts` protect legacy behavior. No real posting HTML is committed.

Open gates are the renderer's user-visible non-Lever route and separate dynamic disclosure, a built worker-copy and desktop IPC/preload smoke check, real-provider quality, installed-app proof, and rights clearance for durable source text. The running 0.5 app and its binaries were not touched.
