# Concise letter writing and readable evidence

## Maintainer requirement

Use a professional, friendly tone and organized short paragraphs. Summarize relevant experience rather than implementation details. Avoid a skills inventory; mention only a few genuinely relevant skills. Never present education/source records as raw JSON in the letter or its normal source display.

The generation prompt now specifies an introduction, a high-level experience/project paragraph and a warm closing; a 150–200-word target, at most two named tools, no grade/date/architecture dump and no inferred degree completion. The model still returns the required structured envelope, but paragraph text must be natural prose. This is prompt guidance, not a claim of verified live-model writing quality.

A shared source formatter presents known education/skill records as readable text both to the model and in letter review. It does not mutate frozen local passages, ordinals, source identities or canonical hashes. Unrecognized source data is not silently dropped or rewritten.
