This is the genuine per-user installation of the updated `CV-Tailor-Setup-0.1.0.exe` from the public GitHub prerelease, not the earlier 0.1.0 binary. The user explicitly approved overwriting that release asset and moving its v0.1.0 tag despite four prior downloads of different bytes. The original installer, checksum/manifest, release metadata and tag refs were archived outside this repository before replacement. Cached old 0.1.0 copies may remain elsewhere; the **current installer SHA-256 is `87eda85f18f16a6a62658e8ed2de805232b90071a4f0993db44e7442ae2bec27`** (257,012,604 bytes).

The downloaded file in Windows Downloads was verified against the published GitHub asset digest. Before uninstalling the prior 0.1.0, the app's native workspace backup action wrote a version-3 JSON backup outside app data; a separate online SQLite backup passed `PRAGMA quick_check=ok`. Both private recovery copies were hashed and are not in Git. The user explicitly chose to remove the previous roaming workspace after backup. The old per-user uninstaller returned exit 0; its executable, registration and Start Menu shortcut were absent. Only that installation's roaming user-data directory was removed; Pi credentials, exports outside the app, and private recovery copies were not deleted.

The downloaded replacement NSIS installer returned exit 0. The new executable reports version 0.1.0 and its installed `app.asar`, Electron-native SQLite binding and bundled LaTeX manifest match the newly verified unpacked build byte-for-byte by SHA-256; its `app.asar` differs from the superseded same-version installation. The new per-user registration and Start Menu shortcut exist. The installer itself did not recreate the deleted regular workspace.

A **genuinely installed-app** smoke used an isolated synthetic workspace. Electron confirmed `app.isPackaged`, version 0.1.0 and the exact physical `app.getPath('userData')` before any test write. A fictional draft prepared via the development-only offline scripted transport was opened in the installed executable; Review showed a source-backed CV title beneath the name, and the *installed* bundled PDF compiler produced a one-page selectable PDF containing the name and title. A local appearance change and native SQLite draft/job state survived closing and reopening the installed app. The isolated fixture was removed. This is installed SQLite reopen and compiled-PDF evidence, not a real provider run or installed editable-Word export check.

The installer is unsigned. The same-version replacement is not an automatic-upgrade guarantee; the prior and current 0.1.0 downloads are distinguishable only by digest.
