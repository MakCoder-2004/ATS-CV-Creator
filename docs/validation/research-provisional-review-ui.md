# Temporary research-analysis review UI (component-only handoff)

This branch adds `src/renderer/ProvisionalResearchAnalysis.tsx` and its scoped stylesheet, but **does not wire it into Saved jobs or ship a complete research workflow**. The parent integration should reveal it only after a person reviews accepted role findings, providing the app-held `researchToken`, and restore focus to its trigger on `onClose`. Place it as an inline Saved jobs subflow; do not add a Tailor CV stage. It invokes named `window.workbench` methods only. No model call occurs on mount, research paste, preview creation, or checking the acknowledgement box.

The person selects **Inspect outgoing data** to obtain the exact user-message payload, chosen Pi provider/model/thinking level, source URLs, unknowns, expiration and notice. The distinct acknowledgement and **Authorize analysis** record consent; **Start analysis** makes the separate, one-use dispatch. This temporary flow offers no saved job, CV-generation, approval or export action. A returned partial indexed-source result is explicitly provisional and its suggestions link to the accepted role findings displayed in the same preview; company background is never rendered as a role requirement. Full text remains selectable in a locally scrollable `pre`. A separate JSON-schema system instruction is disclosed (the outgoing user-message text alone is not the entirety of Pi's request).

Cancellation invalidates the local request generation immediately; late responses cannot publish results. Closing discards the token, cancelling first for in-flight work; a late preview token is discarded. An in-flight provider request may still incur charges. Cancelled/uncertain/errors have no same-consent retry. The component uses an optional narrow `api` prop for focused test injection, otherwise `window.workbench`. Its initial focus stays with the parent, cancellation focuses status, and close restores the originally focused trigger when still connected.

Verification on this branch: `npm run typecheck`; `vitest run tests/research-provisional-review-ui.test.ts --maxWorkers=1` (five passing tests: inert render and consent gate, late preview discard, late cancel suppression, authorized close cleanup, provisional evidence validation). No Electron GUI, installed executable, real Pi provider, Tavily call, or full-suite verification was run. The test environment has no jsdom; state-machine tests exercise the controller and static server rendering checks the initial semantic action. Parent integration still needs an actual visible browser/Electron keyboard, focus, responsive/theme and end-to-end research→consent→analysis check. No claim of shipped or installed behavior is made.
