# Universal research Stage C candidate — temporary Pi analysis

Branch `feat/universal-research-landing` remains **unmerged and unshipped**. Stage C cherry-picked the volatile Pi controller, privacy URL minimization, trusted IPC/preload, revocation and cold-test fix, and the reviewed analysis panel. Conflicts were resolved without removing encrypted Tavily Settings, direct-read transfer or any existing job/CV API. The renderer connects the app-held review token to the temporary analysis panel inside Saved jobs. This candidate is **not release-approved**.

## Visible decisions and boundaries

A selected direct/partial finding is reviewed separately from any model consent. **Inspect outgoing data** reads the app-held reviewed run and selected Pi model, then displays the exact user-message prompt, model, thinking level, source finding IDs/URLs and unknowns. The panel separately discloses Pi's JSON-schema system message, processor retention and possible charges. A review checkbox gates **Authorize analysis**, then **Generate analysis** starts the one-use physical request. Provisional findings stay labeled partial. Results show categories and finding links with human-review warnings, no CV generation or export. Closing the panel unmounts/cancels the originating research session and discards the analysis token; changing the URL, leaving intake or navigating away unmounts both. No persistent research/cached-analysis/backup route is used by the new volatile controller. Existing saved-job CV workflow is untouched.

The dev-only `CV_TAILOR_TEST_RESEARCH=1` seam (disabled in packaged apps) supplies a synthetic partial direct read and synthetic Pi response, and writes a request-count marker under isolated test `userData`. It reads no real source, Tavily key, CV or provider credentials. `tests/electron/research-provisional-flow.spec.ts` exercises public controls and public preload APIs and asserts zero request markers before explicit consent and exactly one afterward, zero saved jobs and no export control.
