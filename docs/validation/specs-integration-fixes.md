| Failing case | Root cause | Fix and focused evidence |

| `draft-records.test.ts`, grouped legacy role | The test transport asked the current generator for several items from one role, which violates the new single-paragraph output contract. | The current transport generates one paragraph for that role. | `draft-records.test.ts`, CV-only origin | The same obsolete transport prevented setup before origin behavior ran. | A current-format role draft exercises CV-only origin and later profile application. Retaining it for deletion also blocked posting edits after cancellation. | Cancellation removes logical ownership immediately. Recovery cannot restart the same run while its earlier request is still unsettled. `tests/analysis-workbench.test.ts` passed, 11 tests. `tests/transactional-job-deletion-acceptance.test.ts` passed, 11 tests, including overlapping runs, late generation and regeneration, and existing rollback cases. |
