# Review evidence gallery

A quick, static visual prototype exploring five ways to arrange review evidence. All names, CV wording, source passages and job details are fictional. This is not the production app or a working review workflow.

## Open directly

Double-click `index.html` (or open it in a browser). No server, installation, internet connection, framework or dependencies are required. The complete prototype—including its CSS and JavaScript—is in that single file.

Use the five labeled buttons to switch arrangements. Select any highlighted CV paragraph to update its source details. In the drawer arrangement, press Escape or use the close button. The theme button switches between light and dark.

This prototype does not check, approve, save, measure, or export a CV. It makes no claims about evidence accuracy or application state.
